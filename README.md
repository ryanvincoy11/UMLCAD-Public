# UMLCAD-Public

Link to UML CAD: https://umlcad.vercel.app/

More info about UML CAD:
UML CAD was created as a way for people to create UML Diagrams without having to pay or log into an account. UML CAD is a browser-based tool that allows the user to create UML Diagrams visually and export them as a umlcad, png, or svg file. UML CAD was built using React, XYFlow, and Typescript and deployed using Vercel.

If you encounter any bugs or issues, please add them to the issues on this Github repository. Thank you!
